# 公司差旅与知识库使用制度演示文档

## 差旅报销

员工因公出差前需要在系统中提交出差申请，并写明出差城市、预计日期、预算和业务目的。直属主管审批通过后，财务会根据城市级别和预算规则进行复核。

住宿报销上限为一线城市每晚 600 元，其他城市每晚 450 元。超过上限的部分原则上由个人承担，除非在出差前获得部门负责人书面批准。

交通费用需要保留行程单、发票或平台订单截图。市内交通优先使用公共交通或网约车普通车型，异常高额费用需要备注原因。

## 发票要求

所有报销必须提交真实、完整、可核验的发票。发票抬头应为公司全称，税号、金额、日期和开票方信息必须清晰可见。

电子发票需要上传 PDF 原件，不建议只上传截图。纸质发票需要拍照上传，并在月底前交给财务归档。

## 知识库问答规范

企业知识库助手只应依据已上传文档回答问题。回答必须尽量给出引用来源，不能把没有依据的猜测包装成制度结论。

当检索结果不足时，助手应该说明没有找到足够依据，并提示用户补充文档或换一种问法。

## Agent 编排约定

系统使用一个受预算约束的 Agent 循环，不设置独立 Supervisor、RAG Agent、Summary Agent 或 Writing Agent。当前上下文足够时模型直接回答；缺少用户长期信息时可调用 `memory(query)`，缺少企业文档证据时可调用 `rag(query)`，并可在预算内使用不同 query 再次检索。

`memory(query)` 只搜索当前用户的普通长期记忆，不能作为企业制度证据；`rag(query)` 只搜索后端已经完成权限校验的知识库范围。企业制度结论必须来自 RAG 证据并保留引用，达到调用预算后应基于已有证据回答或明确说明依据不足。
