# Public RAG Test Documents

这些文件来自公开官方来源，适合用来测试知识库上传、PDF 解析、向量入库、检索、引用和“无依据不编造”的回答行为。

PDF 二进制文件不纳入本仓库。请从下表的官方地址下载到当前目录；`*.pdf` 已被 `.gitignore` 忽略。二次分发前应自行核对来源站点的最新版本和使用条款。
