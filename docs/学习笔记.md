## 企业权限边界

三层 鉴权：

首先

每个知识库有三种状态：private ，department，public

```
knowledge_base_members被显式加入某个知识库的用户，以及他的角色
只有在创建表/显示加入才会写入这个表
```

```
用户查看自己能访问的知识库时：

1. 先查 knowledge_base_members
   获取自己被显式加入的知识库

2. 再查 public 知识库
   所有登录用户可见

3. 再查 department 知识库
   普通用户只能看自己部门的
   管理员可以看所有部门的

最后合并，得到当前用户可访问的知识库列表。
```

个人知识库上传只能且默认L1
获取当前user可访问的所有可访问的知识库id后
个人库默认全部可访问，否则只能查看小于等于自己level的资料
